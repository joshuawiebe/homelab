## What was broken (verified, not guessed)
- All 5 shell scripts sourced `$(dirname $SCRIPT_DIR)/../.shared/log.sh`, i.e.
  `<parent-of-repo>/.shared/log.sh`. Commit ea7c9cb deleted that file, so every script
  exited 1 on its first `source` line.
- `((CONFIGURED++))` / `((SERVICES_STARTED++))` under `set -euo pipefail`: bash returns
  exit status 1 for a post-increment that evaluated to 0, so each script died on the
  first iteration. Reproduced with `bash -c 'set -e; C=0; ((C++)); echo reached'`.
- `tls.certresolver=dnsresolver` in 5 services vs a resolver named `ipv64` in traefik —
  unknown resolver, so Traefik serves its default self-signed cert.
- `IPV64_API_KEY` (compose) vs `IPV64_TOKEN` (template + config.sh) — DNS challenge
  gets an empty token, no certs at all.
- `basicauth.users=${DASHBOARD_USER}:${DASHBOARD_PASSWORD}` — Traefik needs an htpasswd
  hash here, so the dashboard 401s forever. Also `$` in the hash breaks Compose
  interpolation, hence the move to `usersfile`.
- Traefik and Zoraxy both publish 80/443, both "configured".

## What was built
- `bin/homelab`: CLI with up/down/restart/status/logs/urls/config/doctor/snapshot.
  `--dry-run` everywhere, `--json` for status/doctor, exit 1 on doctor FAIL.
- `doctor` is the interesting part: it cross-checks every `${VAR}` a compose file
  references against the service `.env` (catches the IPV64 rename class of bug),
  matches `tls.certresolver=X` against resolvers the proxy defines, flags `:latest`
  and untagged images, rw `docker.sock` mounts, state living inside the git tree,
  port 53/80/443 conflicts, and free space on data_dir + repo.
- `config` is key-agnostic: it reads each `.env.template`, generates secrets for
  keys matching PASS/TOK/KEY/SECRET, and writes 600. It also writes
  `services/traefik/users` from `openssl passwd -apr1` (no htpasswd in the sandbox).
- `snapshot` wraps restic (primary) and borg, with `pre` hooks, `--remote HOST` to run
  those hooks on the source host, retention, `check --read-data-subset`, and
  notifications to Gotify / a dead-man's-switch ping URL.
- Compose: images pinned via `${X_IMAGE:-...}`, watchtower now `--label-enable`
  + daily, shared `security-headers@docker` and `ratelimit@docker` (50/100) on every
  route, healthchecks for db/redis, nextcloud proxy env, healthcheck-gated depends_on.
